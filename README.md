# r11se.com — The Vault

The music site for R11SE (Shawn Owen). Static HTML/CSS/JS, hosted on GitHub Pages at `www.r11se.com`.

## Deploy
Push to `main`. GitHub Pages serves the site automatically.

## Files
- `index.html` — page
- `styles.css` — styles
- `app.js` — track list rendering + player
- `data/tracks.json` — 31-track SoundCloud catalog
- `CNAME` — custom domain mapping
